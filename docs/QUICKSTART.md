# Quick start

See the maintained [first-component guide](../references/quickstart.md) for generation, loader placement, the curve-division example, manual acceptance and remote path mapping. Installation is in the [README](../README.md).

Every input and output receives a deliberate type hint. The [type reference](../references/type-hints.md) lists built-in aliases and runtime discovery; the [port reference](../references/loader-and-ports.md) defines five-field outputs, legacy compatibility and connection-preserving migration.

Keep one authoritative procedure rather than copying the same setup instructions here. During normal development, read only the reference relevant to the task.
